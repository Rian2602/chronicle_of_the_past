# Arc 3 (Phase 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Arc 3 content to transition from Phase 1 completion to playable Arc 3 experience

**Architecture:** Non-linear progression through faction-determined paths leading to breakthrough tier "Jiwa Terpisah". Features quest branching at `quest30X` level with faction-specific gate quests, new map layouts with tier 3 enemies, boss encounters (`bos_sekte_bayangan`), and RPG mechanics (techniques, artifacts, companion Kestrel). Each quest unlocks via flag triggers from previous content.

**Tech Stack:** Python 3.12+, Rich+Textual CLI, JSON data schemas, existing engine combat/KI systems, save system v2, faction reputations (§8).
