# UX Hotfix Implementation Plan (Berdasarkan Hasil Playthrough)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development atau superpowers:executing-plans untuk mengeksekusi rencana ini secara berurutan dengan checkbox (`- [ ]`).

**Goal:** Memperbaiki dua celah *User Experience* (UX) krusial di Arc 1: hilangnya akses toko (shop) di lokasi awal dan transisi *combat* yang tiba-tiba tanpa kejelasan opsi melarikan diri (*escape*).

**Architecture:** 
1. **Perbaikan Akses Toko:** Memindahkan NPC "Pedagang Kelana" (yang memiliki properti *shop* dan material alkimia) dari `hutan_kelabu` (Peta Tier 2) ke `village_emberfall` (Peta Awal Arc 1). Ini memastikan pemain bisa membeli Kuali Roh dan Resep Alkimia langsung di awal permainan.
2. **Perbaikan Transisi Combat:** Memperjelas umpan balik (*prompt*) di `game_loop.py` saat pertemuan acak (*random encounter*) terjadi dengan menambahkan petunjuk eksplisit mengenai ketersediaan opsi `escape`.

**Tech Stack:** Python 3.12, JSON Data

## Global Constraints
- `python tools/validate.py` dan `pytest -q` harus lulus (PASS).
- Tidak menyentuh file *core combat* (`src/engine/combat.py`).

---

### Task 4: Perjelas Instruksi Melarikan Diri di Peta Dunia

**Files:**
- Modify: `src/core/game_loop.py`
- Test: `tests/test_game_loop.py`

**Interfaces:**
- Menambahkan string edukasi (*hint*) ke log pemain saat transisi ke *combat* terjadi, sehingga opsi `escape` jelas disadari oleh pemula.

- [ ] **Step 1: Write minimal implementation**

Buka `src/core/game_loop.py`, temukan titik di mana pertemuan (*encounter*) diinisiasi (kemungkinan besar ada di logika fungsi `_go` atau metode pembantu pertemuan musuh) yang mencetak kalimat kemunculan musuh (contoh: `"{enemy_name} muncul dari bayangan!"`).

Tambahkan peringatan *escape* pada log:
```python
# Cari baris yang merender string ambush/munculnya musuh, ubah menjadi:
lines.append(f"[bold red]{enemy.name} muncul dari bayangan![/]")
lines.append("Pertarungan dimulai! (Ketik 'escape' jika ingin melarikan diri)")
```

*(Catatan agen pengeksekusi: Gunakan alat `grep_search` untuk mencari "muncul dari bayangan" di `game_loop.py` dan perbarui area tersebut).*

- [ ] **Step 2: Run test to verify it passes**

Run: `pytest tests/ -q`
Expected: PASS (Pastikan pengujian log yang ada tidak hancur akibat baris tambahan ini; jika *test* rusak, perbarui asersi *test* tersebut).

- [ ] **Step 3: Commit**

```bash
git add src/core/game_loop.py tests/
git commit -m "feat(ui): tambahkan petunjuk eksplisit untuk escape saat disergap musuh"
```
