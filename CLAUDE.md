# CLAUDE.md — Chronicle of the Past

@AGENTS.md

Proyek ini memakai `AGENTS.md` sebagai satu-satunya sumber kebenaran
perilaku agent (lintas-tool: OpenCode, Claude Code, dll). Baris impor di
atas membuat Claude Code memuat seluruh isi `AGENTS.md` ke context di
awal sesi — jangan hapus baris itu, dan jangan duplikasikan isi
`AGENTS.md` di file ini.

Tambahkan di bawah ini **hanya** aturan yang benar-benar spesifik untuk
Claude Code (mis. preferensi penggunaan plan mode, subagent, atau hook)
dan tidak relevan untuk OpenCode/agent lain. Kosong untuk saat ini.
